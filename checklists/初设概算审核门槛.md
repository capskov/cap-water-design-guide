# 初设概算审核门槛｜提交前逐项勾选

## 资料闭合
- [ ] 明确项目性质（新建接入/市政迁改/建成区管网优化）、投用功能和权属界面。
- [ ] 现状主管管径、**真实外径和材质**、水压、接驳许可、停水或带水作业条件已有依据。
- [ ] 平纵标高与原地面、拟建道路、河床与其他专业冲突进行联核；示意地形不直接作施工控制高程。
- [ ] CAD图单位、坐标、量距方式已核；如影像外部参照已打包。

## 井室与管件闭合
- [ ] 接入点闸阀布置及现状阀门系统关系合理；分段隔离满足本次运维边界。
- [ ] 每个**独立可排空隔离段**都检视高点排气、低点排泥与放空路径。
- [ ] 河道两岸能停水隔离、低点排泥能在岸侧维护；井室不误放河床。
- [ ] 水表井内前后阀、水表、过滤器、倒流防止器是否需要、器型、计量直管段、拆装距离、排水方式齐全。
- [ ] 07MS101-2／12S108-1／10S505适用；非标复合井**没有套用标准井原配筋**。
- [ ] 平面/纵向转折弯头数量按安装条件核定；三通、短管、盲堵、法兰附件、支墩/防脱无漏项。
- [ ] DN/Φ/De、材质、PN/压力等级、阀门型号和限位补偿接头类型一致。

## 交叉穿越与施工
- [ ] 普通过路/交通导改、河道、燃气、雨水、地铁各按边界分别判断，**不自动加套管**。
- [ ] 工作管、套管内径、承插口最大外径、支架、端封、防腐、穿入工艺与井坑位置能施工。
- [ ] 明挖/顶管的**施工方法与永久保护结构分开描述/计量**。
- [ ] 有深槽/高地下水时已提出地勘、支护、降水和安全专项要求；降水井或沟槽共用不重复计。

## 工程量与价格
- [ ] 工作管各材质长度之和=全线安装总长；套管和工作管分别统计，拆旧长度单列。
- [ ] 节点材料表=井位+管件+设备和大样图数量，水表前后阀不重复算为独立井。
- [ ] 井坑只计相对主管沟槽的增量挖方；管身/基础/砂区/井体/支墩占位进入土方平衡。
- [ ] 明确天然密实方/压实方/松方换算，与实际土质及套项口径对应。
- [ ] 若使用2025北京概算标准：确认章节与计量、定型井包含工作内容，未计价主材和阀门安装不重复。
- [ ] 钢质管保温、防腐、玻璃钢保护层和端封逐项有相同的技术规格与单价依据。
- [ ] 项目明确排除的道路恢复、消火栓、二期等不进入本次主概算。

## 交付
- [ ] 最终设计说明中**不出现错误的上一版工程量**；只在变更/审查回复保留对比。
- [ ] 保留“实测/文件实载/估算/待核”的来源状态；设计需补的地勘/权属/厂家条件列清。
- [ ] 交付DXF已结构校验，图层、节点编号、表格可编辑，卫星影像资源可打开。

## V2.2｜发布前检查新增项

- [ ] 明杆与暗杆型号对应正确：明杆软密封闸阀候选Z41X-16Q；不把旧案Z45X-16Q修改历史事实。
- [ ] 下凹穿越的真实管道纵断已核局部高、低点；双侧隔断/PQ/PN按运维必要性确定而非套井数。
- [ ] 共井先按外包络宽度筛选标准井型，但阀体、法兰、全开阀杆与井壁、检修净空、结构配筋均复核。无适用标准不得标标准井。
- [ ] 共槽双管土方、井坑增量、阀门数量及安装定额未重复计量。
