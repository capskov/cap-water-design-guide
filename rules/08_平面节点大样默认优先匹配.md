# 08｜平面节点—典型大样—概算工程量：CAP默认优先匹配规则（V2.1）

> 适用：市政/园区/乡村管网及独立接水的概算方案、初步设计，尤其用户只有概略路线和有限高程时。此文是**默认优先匹配**而非施工图定型标准。新建与迁改分支、产权单位审批、规范、实际纵断、地勘及现场管线条件优先级高于任何默认值。
>
> 证据说明：本轮实际读取并提取了《王佐法庭20261029给水平纵及大样图》《云岗路20261108给水平面及大样》《王佐水管站/地铁1号线支线给水管线迁改》三个源DXF及云岗路材料表修订DXF的块名、标题、对应节点和可读材料表。大部分“典型大样”的管立得构件是 `ACAD_PROXY_ENTITY` 代理实体，不得把仅识别出的块名说成已完整核验了设备精确位置或结构净尺寸。参 `cases/原始DXF节点核验_20261117.md`。

## 一、设计自动化的最小闭环（必做）

`现有条件/控制点 → 管线分段 → 候选节点及桩号 → 节点类型编码 → 选择同口径典型大样（或标注新增非标大样）→ 展开设备和管件BOM → 井室图集/非标工程量 → 基础土方/措施 → 全表数量闭合与重复计价检查`

每个节点是独立对象，字段建议为：`项目/支线号，节点ID，测距桩号，路线坐标，主管DN与材质，节点类型FM/PQ/PN/SB/普通弯点/三通，功能来源，阀设备列表，管件列表，井室结构，图集页码/非标图号，管内底高程，覆土，土方增量，依据等级，待核风险`。保持“路线顶点 / 测量控制点 / 实际有设备节点”三类数据分开。允许概算期间新增、平移、删除无功能折点，不影响原始线路引用。

## 二、默认布置顺序（候选井位，不是硬性间距）

| 排序 | 触发场景 | 初步布置及与其他井合并的原则 | 计量影响 |
|---|---|---|---|
| 1 | 在役主管上停水接出新管 | 接水处优先设支管隔断闸阀井FM；现状主管是否另加上下游隔断，必须看既有阀位及停水范围 | 接入三通/异径件/主支管过渡件、DN闸阀、拆装接头/短管、支墩、井室与接口措施 |
| 2 | 向独立园区或用水单位交水 | 终点设SB计量节点：前后隔断、水表、可拆过滤组件、适用的防倒流保护、拆卸接头和排水/远传；判断是否需计量前排气 | 至少按成套计量井方案暂列，井尺寸由实际设备、前后直管段和维修空间反推，**不可随意照搬标准井尺寸** |
| 3 | 连续长管线路段 | `[E/H]` 以约350～500m为普通分段阀门井候选尺度，优先让井靠近可检修的路口、施工分期界面或产权管段；若总长约700m且两端都有控制阀，可先试算1座中间FM，再核停水条件 | 每处新增FM通常使闸阀、限位拆卸、法兰短管、井室和扩槽土方增加；不等于每350m必须一座 |
| 4 | 真实管线纵断局部高点、隆起、长缓坡空气风险 | 设PQ空气阀节点并核口径与空气排放路径；若一处多阀且能保持净空，可考虑组合井 | 排气三通、复合空气阀、必要隔离阀、拆卸件、井室；并非每个PQ都要新增一台**主管全通径**闸阀 |
| 5 | 管线纵断低点、隔断后无法排空段、河道深埋低点 | 设PN排泥/泄水节点及可维护的安全排水出路；不预设排入雨污水管网 | 排泥三通、排泥控制阀、支管弯头/排泥引管、湿井或集水抽排、井室；应核防倒流污染 |
| 6 | 平面/纵向转折 | 常规弯点不一定建井，先判承插接口可允许偏转 vs 需弯头、竖向弯头、抗推支墩/防脱 | 依实际角度和施工管件统计：11.25°/22.5°/45°/90°，不要按绘图顶点机械一折一点 |
| 7 | 三通/预留接水支口 | 仅实际运行或确认的预留支口配置三通、端阀与盲板/堵头，必要时支墩和阀井 | 预留支口与取水三通分开，不凭示意路线自动多计支管 |
| 8 | 桥河、铁路、主干路、高压燃气、地铁、雨水箱涵等 | 先核监管及产权要求、平竖净距、施工风险与可维护性；决定隔断井、护管/保护涵及施工方式 | 套管与**顶管施工方法**分别列项，支架、端封、防腐、防脱、临时导改专项检查 |

设计中尽量不将井置于河道、机动车危险通行处或难以抽排检修的位置。可以**一井多功能**，但要先满足结构净空、人员安全、阀件拆装和排水。不能为减少井室数量把PQ、PN、SB无依据强制合井。

## 三、基于实际CAD的四类典型节点展开矩阵

以下构件组合是**概算BOM默认核项模板**，不是断言所有图块内部每件的安装顺序、件数或尺寸相同。已有正式节点大样、生产厂家设备总长应优先取其准确组成。

| 编码 | 标准功能 | 最少需要逐件核查的设备与管件 | 来源与偏好 |
|---|---|---|---|
| `FM` | 主管/支线隔断与停水分段 | 相应DN闸阀或经批准的蝶阀、法兰与接管短管、拆装接头/双法兰限位伸缩器、管道外型变化连接件、支墩、防水穿墙、检修井 | 法庭J1FM-1；王佐水管站DN300/DN500历史节点使用蝶阀，云岗路修订版DN100/150用Z45X-16Q软密封闸阀；不能跨时期一刀切 |
| `PQ` | 高点排气/吸气 | 同主管口径排气三通（DN×DNair）、复合排气阀、该排气支路必要的隔断阀、专用连接件/法兰、可能的临时盲堵/两侧短管、排气阀井 | 法庭4处：DN100×50排气三通4、DN50复合空气阀4；另有DN100×100三通4与盲堵4及配套件，属该版特有完整节点，不是每个新项目必配 |
| `PN` | 低点排泥/隔离段放空 | 主管×排泥支管三通、排泥控制阀、90°盘插弯头（如实际需要）、排泥支管至安全收集点、操作井和湿井/抽排接口、连接附件 | 法庭3处：DN100×65排泥三通3、DN65蝶阀3、DN65 90°盘插弯头3；云岗路最新版有用Z45X-16Q替代DN65/DN200蝶阀的局部项目决策，需二选一 |
| `SB` | 总计量与防回流 | 表前后各一隔断阀、水表、T型过滤器、经回流危害分级确认的倒流防止器、可曲挠橡胶接头/限位伸缩器、前后直管段、集水排水及防淹、远传接口 | 法庭20261029 **实际CAD材料表**：DN100表1、前后软密封闸阀2、T型过滤器1、倒流防止器1、可曲挠橡胶接头1、DN100 B2F伸缩接头1；不能再用7月文字未载防倒流器推定10月CAD没有 |
| `BEND` | 线形水平/竖向转折 | 每个实际管件转角、角度及类型、上下游接口、必要抗推、防脱件、相应铺管长度扣减 | 法庭材料表DN100 45°双盘弯头14，对应一般弯点7+排气4+排泥3的历史拆分口径；不能据此认定其他项目PQ/PN必须各配同款45°弯头 |
| `TEE` | 接入、分叉和预留 | DN实尺三通、法兰/承插过渡、支管阀、端堵或闭合端、支墩、分区运维逻辑 | 法庭DN250×100接入三通1；本次安置房DN250×150要按实际现状主管条件另出清单 |

**法庭20261029专属计数佐证，不可泛化：**B2F DN100 8套=PQ4+PN3+接水FM1，SB另列1套，共9；DN100插盘短管30件=一般14+PQ8+PN6+SB1+FM1。资料可核对但没有复核原生CAD代理件的具体拆装朝向。若改用不同厂商的成套阀组，BOM必须整体重核而非简单按经验数量相乘。

## 四、默认管材选型、埋设和保护：由工程类型分流

- **常规埋地生活给水（清楚要求球墨时）**：优先K9球墨铸铁管、T型柔性接口（按压力、口径、现状与审批要求核）；阀门及可拆部位用法兰。球墨外防护以产品体系为准，不自动把绿色护层写作3PE。法庭为喷锌+挤塑PE，园区另有其他厂家外防护方案，出概算需分清成品材料已含的防腐。
- **特殊管线交叉/穿套管的工作管**：若要求钢工作管，明确外径×壁厚、钢号、衬里卫生要求、连接工艺、防腐等级、是否能穿过套管承口/支架；云岗项目曾采用Φ530×10衬塑工作钢管和Φ820×14钢套管等项目化选型，不是任何DN500自动配置。
- **热水/供热管**：从生活给水分支跳出，另核介质温度压力、热胀、补偿、保温厚度、外护防水和耐热涂层；此前DN200讨论中的Φ219×8只作为候选规格，不固化为必选，更不能照搬给水柔性接口体系。
- **常规市政道路穿越**：并非必须加保护涵或套管；先核道路管理部门条件、开挖许可、交通与荷载、覆土/接口、二次施工风险。**穿越主河道/燃气/地铁**须单列专项判断和运营保护条件。明开挖/顶管是施工工法；套管/保护涵是永久防护，两个轴独立判断。
- **结构井室**：优先根据设备、开盖与人孔检修条件选图集；原图常见 `07MS101-2`（法庭：阀井页66、排泥砖井页58、排气钢筋砼井页162、水表井材料表页147），项目化选型须核查对应版本的图集表、井尺寸和适用管径；成套复合水表井超出标准设备组合则按非标井说明，不得虚称直接套用标准图。支墩选型可参 `10S505`，须核算实际工作压力、土体承载和抗推。

## 五、缺少施工图/勘察时可用于概算的默认断面（显式标[E]）

| 参数 | 默认优先取值 | 注意条件 |
|---|---|---|
| 管顶覆土 | 1.50m左右，且结合当地冰冻、荷载、冲突及批准控制高程复核 | 这是历史项目常用概算假定，不是所有城市、所有位置的最小规范值 |
| K9球墨外径 | 用厂家公称口径对应产品外径，须从管材表/厂家确定 | 不用DN直接代替Do；承口和套管间隙另核 |
| 管底垫层 | 150mm中粗砂/砂石基础作为正常地基默认值 | 不良地基需先按勘察调整厚度和换填 |
| 沟槽底宽 | `B = Do + 2×0.50m + 支撑占位`（无支撑概算） | 每侧500mm是CAP惯用保守工作面；现场必须核GB 50268和支护施工条件 |
| 开挖深度 | `H ≈ 管顶覆土 + Do + 垫层厚度` | 以管顶/管底实际设计高程分段控制；不得用平均地面高程忽略局部深槽 |
| 明挖放坡 | 地质未明时可设置 `1:m = 1:0.5` **概算情景** | 不代表施工安全允许坡率；受土质、地下水、场地及周边建筑影响即另核与计价 |
| 沟槽开挖 | 在无工作平台、单级放坡时 `A = H(B+mH)`，分段 `V=ΣAi×Li` | 同槽双管必须按共同槽宽计算，不能两次套单槽 |
| 管周细料回填 | 管腋、两侧至管顶上0.50m优先按设计要求计，中粗砂与管底基础分列 | 用对应开挖轮廓扣除管道实体占量，不能全宽简单相乘且重复加垫层 |
| 井坑增挖 | `V井坑实际 - V与主管沟槽重合`，只计增量 | 井室实体占体积、操作面、井周回填与回填土层次另算 |
| 余土与外运 | 同一体积状态下做挖—回填—井体及材料置换平衡，转换天然/压实状态时记录采用系数 | 不得直接把“天然挖方 - 压实回填方”当标准外运数量；需按适用定额口径 |
| 测试 | 压力试验、冲洗消毒、卫生检测、通水接驳、产权移交单列 | 根据合同清单/计价规则判断是否已包含在铺管工作内容中 |

工程量绝不自动添加已明确排除的道路拆复、总价措施、降水或交通导改。对专项风险，仅列“待核暂列”而不隐瞒。

## 六、CAP数量闭合与源CAD执行门槛

- **先生成节点索引再算BOM**，同一种同口径节点可指向同一个典型大样，平面各节点有独立唯一编号，如 `J1FM-01/J1PQ-02/J1PN-03/J1SB-...`；无井普通节点仅作BEND/TEE。
- 以 `BOM总量 = Σ(节点类型 × 节点对应组件数) + 特殊节点逐项明细 + 主线管材量` 得出初步物料；**不能假定阀门井=一个阀门、PQ=一座主线阀井、每个折点一个弯头**。
- 输出表分列 `单位/主材数量/设备数量/井室数量/土方/其他措施`，对已含工程内容的定额清楚作“含/不含”标识。直管长度与管件占长应按概算计价口径确定，不把节点里每根短管重复加进总长度。
- 面向原生管立得CAD：`INSERT`不一定是普通图元；原样DXF的节点块在本次多数含`ACAD_PROXY_ENTITY`，**文字/块名可解析不代表几何、尺寸及空间可验证**。需要原生软件导出可视PDF、爆炸代理构件副本或截图后，才能将典型节点精确转化为可执行的连接拓扑。

## 七、触发式提问与临时可用默认值

**必须问或需明示暂列**：1) 现状主管能否停水、主管材质和现状阀门位置；2) 水表井用途及供水管理部门关于倒流防止器的规定；3) 埋深下是否穿重大现状设施、是否可明开挖；4) 沿线高程资料是否足以识别高低点、低点排水去哪里。对未有纵断的项目，不得无依据认定排气阀=0或终点必能并入表井。其他信息优先采用已经核实的历史习惯估算，留出工程量调整空间。

**默认方案建议呈现两档，而非假装精准：**A=基本设施（起点/终点控制＋适量中途FM、只设已有证据支持的PQ/PN）；B=含现场不确定性暂列（增加若干待核PQ/PN、特殊连接和井坑措施）。必须标出B档增量，审查时能解释为何暂列。
