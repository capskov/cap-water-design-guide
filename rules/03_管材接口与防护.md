# 03｜管材、接口、防腐、保温及保护管的选择

## 常规管线与水质

| 选择条件 | 候选材料/体系 | 依据与限定 |
|---|---|---|
| 新建DN100～DN500一般直埋生活给水 | K9球墨铸铁管，T型柔性承插，接口胶圈符合涉水卫生要求 | `[H]` 某独立用水单位DN100、某园区DN250及某城市主干路常规管段；K9壁厚级别≠设计压力等级 |
| 某独立用水单位小口径地面环境 | 球墨铸铁管内水泥砂浆衬里，外喷锌≥130g/m²+挤塑PE护层 | `[H]` 某独立用水单位后期说明；不是所有厂家产品的必然统一做法 |
| 某园区长距离管线 | K9球墨铸铁管，内部水泥砂浆，工厂双组分无溶剂聚氨酯外涂层 | `[H]` 某园区后期文件按GB/T24596写平均≥1000μm等项目参数；不可自动套到某独立用水单位或新项目 |
| 水源/深槽/燃气复杂穿越、承插不便保护时 | 钢质工作管（无缝或焊接）/内衬PE复合钢管，与球墨主线通过转换件连接 | `[H]` 某城市主干路交叉穿越已多次优化；钢管必须满足强度、饮水卫生、防腐和焊接检验 |
| 需要套管保护的工作管 | 工作管+钢/钢筋混凝土套管+独立支承/端部封堵/防脱体系 | `[N/E]` 需计算最大安装外径及最小施工环隙，不能只以DN核定套管 |
| 热水管/供热管线 | 按温度、压力及管网标准另做钢管、焊接与保温设计 | `[Q]` 不是生活给水材料的一键套用；曾讨论DN200选Φ219×6/8，软件默认Φ219×8，但尚无可普适确认的设计计算 |

## 用户历史钢质给水案例（区别版本）

- `[H]` 某城市主干路旧版/08月审核资料：部分工作管D530×10无缝钢管217m、D630×16钢套管1035m，与常规DN500球墨段分开计价；另曾出现Φ630×16套DN500球墨管的布置争议，安装可行性必须按**最大承插口外径、法兰、支架及管段推进**复核。
- `[H]` 后续方案阶段已确认：主线DN500局部采用**Φ530×10内衬PE复合无缝钢管工作管90m，外设Φ820×14 Q345B焊接钢套管90m**；DN100/150内衬塑复合钢管拟穿Φ377×8保护钢管；若资料中出现不同年份、不同长度或管径，必须按指定项目及施工图版本比对，**不是标准统一配法**。
- `[H]` 阀门DN200/DN65排泥阀曾统一选Z45X-16Q闸阀；DN500限位补偿采用**双法兰松套限位补偿接头（VSSJA-2/B2F）**，不能与单法兰传力接头混称。

## 套管净空校核清单

1. 工作管**管身外径、最大接口外径/法兰外径**和接口允许偏角、长度、连接方式。
2. 套管实际内径：`套管公称/外径 - 2×壁厚`；钢筋砼套管实际内径及承插口另核。
3. 绝缘定位支架厚度、允许偏心、垫块强度与间距、弯道与进出管工序。
4. 能否整体穿入、逐根穿入后连接、分段焊接、工作坑空间及坡度；必要时增加套管规格。
5. 套管端部柔性密封、防水防泥砂、防腐和结露；套管是否需要通气/排水，避免无排水条件的封闭积水。
6. 混凝土套管抗浮、基础、承插密封和施工期荷载；钢套管焊缝、材质、3PE外防腐及补口一致性。

## 防腐/保温体系分开看

- `[H]` 钢质给水外防腐在某城市主干路经常选3PE，内防腐/内衬PE复合材料按供水卫生要求另核。**3PE是钢管防腐，不代表球墨铸铁管常规外护全都叫3PE**；球墨的喷锌+PE护层和双组分聚氨酯也不是同一概念。
- `[H]` 某城市主干路局部穿高压燃气浅埋节点曾采用**钢套管外50mm硬质聚氨酯瓦壳+玻璃钢保护层**。只在冻深/浅埋/长期低流量及穿越条件需要时考虑，不对每米常规给水自动计保温。
- `[H]` DN200热水管曾比较Φ219×6与Φ219×8，后者为广联达候选值；正式选择需按介质温压、腐蚀余量、热膨胀、支撑跨度、施工焊接和相关热力标准复核。保温主材、金属或玻璃钢外护层、保护层按工程系统分开列量。
- `[Q]` 对“3PE价格每米”先按外周面积、厚度等级及内外防腐工艺询价；对“保温体积”按保温截面积×长度、保护层按实际外包面积，不将环氧煤沥青玻璃布定额自动当成玻璃钢保护层。

## 管材决定的下游变化

球墨承插直埋 → 配套弯头/三通+止推墩或自锚，柔性接口检查；钢工作管 → 焊缝与无损检测、内外防腐补口、阴极保护适用性分析；复合钢管 → 内衬连续性及端头处理；钢套管 → 间隔支架/端封/防水/焊缝；保温管 → 保温层+防水外护+穿井处理+热胀冷缩。不要把一种材料的典型做法套到全部品类。
