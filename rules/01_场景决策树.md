# 01｜场景决策树：先分工程性质，再选保护与施工方式

## A 工程性质

### A1 新建接水 / 某园区供水
- `[P]` 核实用水量、设计流量、接水余压、末端标高、用水性质、独立计量点、是否承担消防储水补水；明确本工程止于计量井出口还是院内配水。
- `[H]` 某独立接水工程：DN100 K9，后期终版约712.871m，接现状供水干管；院内消防池补水与生活供水分界单独说明。某某园区给水工程：DN250 K9，主管5758.148m，供某园区生产/生活与消防池补水，末端设置可维护计量及防倒流。
- `[Q]` 若图上只给起终点和粗线，检查“相邻现状水源线、建筑、道路、河道、缓冲用地与权属”，不能原样照搬粗线。

### A2 既有主管迁改 / 分期还建
- `[H]` 某城市主干路经验：按既有两道DN500分别承担的供水系统功能组织迁改；非单纯新增扩容，不得因两条线并排而随意合一。
- `[P]` 迁改边界按道路分期、现状恢复可用性、权属运维和接驳停水窗口确定；新建、拆除、利旧、临时保护分别统计，**拆旧长度不要求等于新建长度**。
- `[Q]` 新旧管切换能否分期、是否要临供、交叉过路是否可全部明挖，受施工与交通管理条件约束。

## B 路线遇到什么

| 场景 | 第一判断 | 方案候选 | 必须核查或向用户问 |
|---|---|---|---|
| B1 绿地/低交通土路 | 地形、地下水、埋深、可开槽宽度 | 明挖直埋球墨铸铁 | 土质、管区回填、绿化恢复是否计 |
| B2 一般道路 | 交通许可、现状结构和其他管线 | 分段明挖/半幅施工，必要支护；是否套管另评 | 能否占道？恢复边界？是否需导改？ |
| B3 主干路、重要路口 | 长期开挖可否接受、工作坑条件 | 明挖+交通导改或机械顶管/其他非开挖 | 交通组织、井坑位置、地质水位和管线间距 |
| B4 与燃气交叉 | 净距和规范规定、相对上下关系、燃气权属 | 优化高程、套管保护、非开挖等比较 | 管线外缘净距、施工限制、套管外径和封堵系统 |
| B5 雨水大管/箱涵交叉 | 雨水顶/底高程、净距、顶覆土/底净距 | 上跨优先或下穿；有条件钢套管、改变线形 | 是否碰撞结构/需要专项验算；不可只看中心标高 |
| B6 地铁/重大结构 | 保护区、沉降控制、运营方许可 | 通常特殊保护及监测；钢套管或保护涵应专业论证 | 地铁管理要求、结构外缘净距、施工工法 |
| B7 河道/排洪沟 | 河床冲刷、岸坡、设计洪水、河管许可 | 明挖围堰导流+套管/箱涵；受限考虑非开挖 | 设计冲刷线、河道导流、抗浮、防脱、是否备用管 |
| B8 深槽/地下水 | 水位与槽底、槽深、边坡条件 | 放坡、支护、井点/管井或集水井；专项 | 危大工程判定、地勘、稳定性、涌水与降水时长 |
| B9 浅埋/受冻 | 覆土与冻深、道路荷载 | 加深、局部结构保护、符合工况的保温 | 水力连续性、运营停水、保温材料保护层 |

## C 保护措施不是施工方法

- 钢套管、混凝土保护套管、混凝土箱涵 = 管道永久防护构造。
- 明挖/分段导改/机械顶管/泥水平衡顶管 = 施工工法。
- 工作井/接收井 = 施工临时构筑物，是否作为永久井需另设计；**不可把工作坑误计为永久阀门井**。
- 穿越需要同时给出“工作管材质+尺寸、套管材质+尺寸、环隙/支架、端封、管区保护、施工方法、基础、监测、抗浮或止推”，而非只给一句“钢管套钢管”。

## D 关键条件缺失时的默认输出

- 已知粗略路线和工程边界：先做概算方案，允许合理新增节点和工程量暂列。
- 未知净距、地层或现状管外径：不得自称能施工，也不出具有唯一性的套管尺寸；列两种可比选工法以及影响造价的主量。
- 用户明确某区段不计道路恢复、消火栓或二期：**不得暗中加进总概算**；只在待核提醒说明可能存在与项目边界相关的工作。
