# 07｜CAD平纵、节点大样、设计说明与交付

## 一张图至少分清四类东西

- **控制资料**：卫星图、地形及高程点、现状管线、道路/河道/燃气/雨水等外部边界；与设计成果分层，不得错误覆盖。
- **拟建管线**：新建主线、接驳、设计管径及材质、工作管/保护套管不同图例；新旧拆管、保护构造线型区分。
- **可维护节点**：阀门井、排气井、排泥井、水表井、支墩、端封、保护涵起终点；编号、桩号、坐标/地面/管底高程、关联设备和图集指向。
- **数量/审核信息**：主要材料表、主要工程数量表、设计假定、待核事项、版本和来源。保持Excel/DXF/说明书的数据一致。

## 用户已形成的出图结构

`[H]` 某城市主干路施工图目录曾分为现状给水、平面图、工程数量表、纵断面、节点大样、开挖断面、节点一览、检查井定位、局部边坡支护与数量等专题。将图上的节点、纵断和工程量互相交叉核对，比只给一条管线路线图可靠。

`[H]` 用户偏好在原CAD图内补可编辑表和节点标注；不另起一张无关底图。节点及其连接件需要同时标明规格（全盘/双盘/盘插、规格、角度、数量）；DN口径、钢管外径壁厚、钢套管外径壁厚使用不同表达，不混淆DN/Φ/De。

`[H]` 对项目汇报图和施工图的表达不同：汇报图可标冲突点颜色、交通导改方向等，但施工图要有标准图例和高程控制。用户前期把红色用于高程冲突、蓝色用于需保护，色义必须依据所在项目既有图例，而非跨项目统一。

## 一张表的骨架

| 列字段 | 必选目的 |
|---|---|
| 分项/名称 | 对应可套的工程量项、不要只写“管件一批” |
| 规格型号与构造 | DN150 K9、Φ530×10、Φ820×14、阀门型号、井室图集等 |
| 单位与数量 | m、m³、座、台、套、t等按专业 |
| 位置/节点关联 | W1、J1FM、0+360等；有条件用桩号范围 |
| 依据状态 | `实测`/`文件实载`/`推算`/`概算暂列` |
| 说明及待核 | 工程量算法、图集选型、外部限制 |

## 设计说明书书写原则

1. 不写“从原方案修改了多少/原来是什么”除非文本是审查回复或设计变更。最终出图说明只描述**现行最终设计条件和数量**。
2. 结构顺序建议：工程概况/任务与范围→设计依据及权属→现状供水系统与迁改必要性→管位、材料、接口、纵断、埋深→交叉保护与施工工法→阀门井、排气排泥、计量→土方/防腐/保温→降排水与交通→试压冲洗/消毒→移交及注意事项。
3. 特殊方案应写清**净距、高程控制、规格、长度、施工步骤、必要性依据**，不能仅写“为保障安全采取保护措施”空话。
4. 接驳施工通常“新管线先建并试压消毒 → 取得停水许可后端头碰接 → 切换供水 → 拆除退出运行的旧管”，根据现状调度制定临时供水与风险预案。
5. 旧线拆除和新线长度不同属正常；预算按各自图示统计，不要为让两个总长相等而虚构拆除范围。
6. 深槽支护、降水、保护涵以及顶管都属于条件性章节；项目全明挖且没有这些场景时不机械复制。

## DXF技术检查

- 图纸坐标是否为地理经纬度而标成米；CAD `INSUNITS`只是标签，不代表真能用米量距。经纬度图先做局部工程坐标或分段实测；保留坐标转换说明。
- 卫星影像引用改相对路径，与DXF打包交付，避免用户电脑的绝对路径无法加载。
- 表格文字为CAD可编辑TEXT/MTEXT或原生表实体，图层分开（WATER_NEW/WATER_WELL/WATER_CASING/QTY_TABLE/NOTES等）。
- 防止标注遮挡卫星底图要点；纸面能看清线型粗细及图例，无需重复过度花哨渲染。
- 每次交付至少包括DXF、底图依赖、工程量公式说明和版本更新摘要；不能把图上的“暂估井位”伪装成已精确勘测放样点。
