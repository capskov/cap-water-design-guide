# 06｜概算工程量、土方、套项及常见审减风险

> **V3.0阅读原则**：这是一份供Agent参考的工程经验，不是强制算法。应先确认现行规范和项目条件；初估尽量覆盖真实可预见的费用风险，但不虚增设备、叠加互斥方案或重复工程量。参见 [投资包络与专业判断](00_投资包络与专业判断.md)。

## 先选适用的计价体系

- `[N]` 北京2025年《北京市建设工程计价依据——概算消耗量标准》自**2026年5月1日起施行**，适用于本市初步设计概算，配套执行规定见京建法〔2026〕1号。用2025版概算消耗量标准时，引用“第四册市政管网工程上/下册”和“第一册通用项目”，而非旧2016版概算定额。
- `[N]` 第四册上册：**第三章给水管道铺设与附件安装、第四章给水管道附属构筑物**；下册含**第十章防水刷油及防腐保温、第十一章非开挖施工**。土方、支护、降排水等结合第一册通用项目。
- `[N]` “新建市政接水”与“建筑内部管道”应先确定碰头界面，是否适用市政还是安装或构筑物专业，不可一个单位工程混套多种体系。
- `[Q]` 具体定额编码、未计价主材和消耗内容应以编制期完整册及当地计价软件为准；**下面曾用子目编号是某次审核某城市主干路审核案例，不代表跨项目自动套价**。

## 概算数量应有的主类别

1. 工作管：按DN、材质、等级、连接方式、明挖/顶管/套管内等分段，以m计。拆除旧管另计，不假定拆除长度=新建长度。
2. 管件：全盘三通、异径三通、双盘弯头、盘插弯头、短管、盲堵、钢管焊制管件，**角度及接口形式分开列**。
3. 阀门和计量：主线闸阀、空气阀及其隔离阀、排泥阀、远传水表、过滤器、倒流防止器、拆卸/限位补偿接头，按实际设备数量。
4. 井室和结构：标准井/非标井、混凝土和钢筋、井盖、穿墙套管、集水坑、井室扩大基坑、止推墩、防脱锚固和抗浮。
5. 防护管/穿越：不同材质套管、支架、端封、两端接头、防腐保温、工作井/接收井、围堰、临时导流、支护、施工期监测。
6. 土方/恢复/临建：沟槽和井坑挖填运、砂基础、管区砂、道路或绿地恢复、施工导改、降排水、试压/消毒/水质验收、标志桩。

## 土方计算的版本与口径

- 沟槽外径`Do`是**管身最大相关外径参数**，不可把DN直接当Do。`C=管顶覆土`, `t=基础厚`, `w=每侧工作面`，如底宽`B=Do+2w`，深度`H=C+Do+t`，两侧放坡`1:k`且不含分台、施工排水沟时：`A=B×H+k×H²`，全长挖土`V=L×A`。仅在条件满足时适用；跨越井、深坑或支护区段逐段算。
- 井室扩大基坑只能取`全井坑量 - 已纳入主沟槽交集挖土`作为增量；井体实体体积、垫层、管身、砂和结构保护占位应在回填/外运平衡中处理。排泥支管沟槽和独立湿井按不重叠部位另计。
- `[H]` 某独立用水单位后期全线DN100 K9约712.871m，用户采用每侧0.5m工作面，DN100管外径约0.118m，底宽1.118m；沟槽挖方2532.753m³、基础165.145m³、管区砂649.355m³、回填土1710.458m³均按该项目图纸给出。**并不是所有DN100国家规定都必须底宽1.118m**。
- 北京2025口径下，挖/装/运天然密实体积与回填压实体积要做口径转换。某城市主干路审核文件曾以压实体积×1.16折算天然密实回填，再做余土估算；正式采用必须复核该项系数的适用土类及土方调配，不能见到挖方就减压实回填得外运。

## 某城市主干路某次审核出现的错误→以后自动校核

| 常见错误 | 规则 |
|---|---|
| 拆除旧DN500管套新建球墨铺设子目 | **完全不同的工作内容**，应按拆除/吊装/外运/回收残值独立组包，不允许用铺设金额代拆除 |
| “回填砂”用路基大面积碾压子目 | 沟槽回填应查“其他部位回填”适用工艺；旧审核建议1-17、1-20（需按正式册和软件核） |
| 阀门井定型子目已含阀门安装，又单套阀门安装 | 不重复安装工机；保留应计未计价阀门主材 |
| 管件数量对，但全盘三通却套全承三通、双盘弯头却按双承 | 不能只按件数，对接口形式、主材和安装方式逐规格核 |
| 钢套管铺设借用给水工作管铺设子目 | 要核是否含试压消毒等不适用套管的工作内容，按借用/补充口径标注 |
| 防腐3PE单价仅按米不同口径倒挂 | 先按面积和等级统一询价，主材价依据区分《北京工程造价信息》与协会市场参考价 |
| 玻璃钢保护层用“环氧煤沥青玻璃布”充当 | 材质和施工体系不同，不能只看面积一样就直接借用 |
| 管井降水两道并排管各计一套 | 实际共槽时应按同一降水系统计量，分段共享井口，不重复计 |
| 喷锚深槽直接套浅槽旧综合子目 | 按土钉/锚杆、钢筋网、喷混厚度、泄水孔、锁口梁、监测拆分并依设计验算 |
| 管道长度与材料表/预算不闭合 | 新管长度=各材质分段长度；钢套管长度与防护图/清单闭合；别把套管长度误算为新供水能力管 |

## 近期审核的量级不能直接做新项目单价

某城市主干路某次审核报告按当时方案约2487.164m给水迁改、约6009元/m（含大口径、套管、深槽喷锚降水等）；**这一含复杂工程措施的指标不适合作为DN150简单明挖管的直接单位造价**。用户明确只要主要工程数量表时，不应擅自编造报价。

## V2.2｜典型阀井及多管共井造价自动展开

- `FM`节点默认比较 `Z41X-16Q`明杆软密封闸阀、法兰附件和拆装接头，阀井净高按阀杆全开要求复核。不得使用暗杆Z45X价目冒充明杆阀。若现有定额/概算子目已含安装，单列主材后不要重复叠加全套安装。
- 双管/多管共井先用外包络宽度检索较大的标准钢筋混凝土矩形井型，若经空间及结构核验可用，井室计 **1座**、设备按实际管数计；不应把“1座井”反推为“只有1台闸阀”。同槽土方应为**共同开挖断面**，井坑增量扣除与共槽重叠部分。
- 无地勘、无局部纵断的特殊下绕段应列暂估PQ/PN或提供两档数量，不能只按平面折线零估。


## V3.1｜直埋保温热水管的概算套项与焊缝检测

对拟按北京市2025年《市政工程概算消耗量标准》第四册下册**第九章热力管道铺设及附件安装**中的“预制保温钢管直埋铺设”计价的工程，章说明及铺设子目工作内容**已包含**：管道普通焊接安装、接头保温、分段与总试压、冲洗等；**接口处现场保温费包含在保温管及管件主材价格中**。不应再单独叠加这些普通工序及已含材料费用。参见[北京住建委发布的2025版第四册下册](https://zjw.beijing.gov.cn/bjjs/xxgk/zcwj2024/qtzcwj/xxyx13/743876492/04%E5%B8%82%E6%94%BF%E7%AC%AC%E5%9B%9B%E5%86%8C%E4%B8%8B.pdf)第九章说明（印刷页181）与预制保温钢管铺设子目（印刷页183以后）。是否适用该章，先核系统工程性质、专业界面和最新概算规定。

**无损检测不能直接等同普通焊接。** 应按介质与管网分类决定检验标准；对适用的城镇供热直埋热水管，CJJ/T 81-2013 §7.1.13提出射线探伤优先、普通抽查不小于25%、特殊穿越等部位100%。CJJ 28-2014 §5.7.27另对管件/折点焊缝、穿越关键设施的焊缝和超声波复检作出规定。但普通生活洗浴热水输送管线**不应未核适用范围便宣称必须全部照搬城镇供热标准**。选取RT（射线）作为阶段参考方案，按重点焊口全检、其他抽检估算，最终由设计/产权/监理/相关标准确定。标准参考：[CJJ/T 81 §7.1施工](https://gf.cabr-fire.com/article-14966.htm)、[CJJ 28全文](https://www.zlglpt.com/book/book_view.aspx?id=1113)。

**演示性数量**：长度约586m、供货节长假设12m，约49根直管和5个弯头可形成约53道线性环向接头；假定10道重点焊口100%RT，其余43道按不小于25%抽查向上取整11道，则暂估RT检测21道；按工作钢管外径219mm，环向焊缝展开长度约21×π×0.219=14.45m。**这些是条件性、可复核的估算数字，不是通用设计比例**；过路关键范围和真实端部连接数量可能增减。以最终选择的计价子目的计量单位为准，不机械按焊口“道”换算为铺管“m”。

共井结构估量可按净空、井壁厚、底板、顶板、各洞口扣减算结构混凝土；钢筋如按经验含钢率换算，必须标明未作配筋验算，且与定型井综合套价不重复。
