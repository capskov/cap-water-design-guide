# 00｜投资包络与专业自主判断——CAP第一原则

**使命：在不违规、不过度设计和不虚构证据的前提下，合理覆盖前期可预见的工程投资。** “包住”指提高对正常可预见工程量、必要措施及合理风险的覆盖，减少方案深化时因漏项而超出估算；不代表保证未来决算绝不会超出，也不代表任意把钱做高。

## 1. 对工程师有用的预算思维

早期投资误差常不只来自材料价格，还来自漏掉功能节点、连接短管与拆卸接头、支墩与防脱、钢套管支架端封、沟槽及井坑、现状管线保护、支护降水、道路和绿化恢复、试压消毒、交通与必要监测等。

Agent应当**主动逐场景检查**这些类别，但每个项目都需满足相应条件。不存在“所有过路必须顶管”“所有深槽必须降水”“所有管道必须加钢套管”的CAP规定；具备技术理由时可以选择更优替代方案。

## 2. 四种费用状态不可混淆

| 状态 | 在概算中如何体现 | 例子 |
|---|---|---|
| 确定项 | 主方案工程量，可核计算 | 既定管径路由、确认的接水阀与计量装置 |
| 合理暂估 | 有说明的主方案暂估量，附后续复核条件 | 初步覆土、工作面、可能的防脱节点 |
| 条件性风险 | 分列风险与触发条件，按批准计价口径处理预留，未证实时不伪称必建 | 可能的地下水降水、受限交通或保护监测 |
| 互斥备选 | 技术比选，只选一套为主方案，其他列差额 | 同一处明挖与顶管、不同保护结构 |

不得自造预备费率、虚构水位和勘察结论，或把互斥方案的全额累加。某项费用若被其他专业、其他合同或项目范围明确覆盖，也不能重复纳入。

## 3. 合理“偏上”的尺度

技术上能够合理证明性能、运行可靠性、维护便利或施工安全改善时，可以优先选择品质较高的管材、闸阀、防腐、节点保护和施工措施；必要的配套管件、支墩、工作面和井坑增量应充分计算。**不得只因为贵就选用，也不能为了维持概算刻意保留无必要工程。**

没有地勘时可以提出概算假定，但必须明示；有条件地预估支护、降水、换填或监测，不可编造“已勘察确认”。条件不成立时应主动核减；条件成立时说明为什么需要增加。

## 4. 面对审计与专家的证据链

对有明显投资影响的措施，尽量给出五项：**工程条件／所防范的风险或解决的功能／选用措施及与低配方案的区别／数量与计价依据／不再需要该措施的条件**。

例如：下穿雨水导致局部凹点，需核低点排空能力、两侧隔断边界和高点积气；排泥、排气不能只凭“过路”两个字强行固定数量。双DN500共井可用外包络约1.56m作为初选井型的尺寸检索，但仍须按实物阀体、法兰和井室检修空间复核。

## 5. 适应不同任务与Agent

快速估算：应主动提出清晰、保守但有理据的假定，尽快形成主方案工程量及条件性风险，不因细节未齐反复提问。改变重大工法或投资边界的缺项可问。

初设/施工图：应逐步以真实资料、计算和规范复核替换概算假定；如果发现原方案过于保守，允许合理下调。更强Agent应能提出比历史CAP做法更合理的专业选择；经验是优先匹配，不是强制命令。

## 6. 每次积累新经验

记录：**发生情形、为何需这个措施、什么情况下可删除、对工程量和成本影响、证据来自哪里**。尽量保持自然语言，避免将判断变成几百条刚性if/then。


## V3.1｜前期费用包络的“防重计价”底线

工程师在概算阶段可以保留偏审慎的标准弯头、管材质量配置和合理的支墩抗推设计，前提是说清楚**暂按什么计算、何时改为真实施工尺寸**。但不能用“包住造价”把适用定额已含的普通焊接、接口保温、试压、冲洗、节点支墩等再次全部列为独立增项。

当用户认可原软件土方，且差额数值接近一根管道的外包体积时，先检查软件是否在回填计算中扣除了该管体。该算术吻合只是排查线索，不是算法证据；不得将体积差直接冠以弃方。

对于焊缝检测，设计必要性、检测比例和概算计价是三层不同判断：检测项目应按实际适用的标准、检验方案以及检测费用归属确定，不因想保留投资就无条件按全线100%另计。
